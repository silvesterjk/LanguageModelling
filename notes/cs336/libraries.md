# Libraries Used and Why

- **torch** - Open-source deep learning framework for building and training neural networks
- **numpy** - Fundamental package for numerical computing with support for large, multi-dimensional arrays and matrices
- **sympy** - Python library for symbolic mathematics and algebraic computations
- **requests** - HTTP library for making web requests and interacting with APIs
- **sqlitedict** - Persistent dictionary backed by SQLite database for key-value storage
- **warcio** - Library for reading and writing WARC (Web ARChive) format files
- **markdownify** - Converts HTML documents to Markdown format
- **tiktoken** - OpenAI's fast BPE (Byte Pair Encoding) tokenization library
- **openai** - Official Python client for OpenAI's API (GPT, embeddings, etc.)
- **wandb** - Weights & Biases: tracks experiments, logs metrics, and visualizes ML training
- **einops** - Flexible tensor operations using Einstein summation notation for readability
- **jaxtyping** - Type annotations for JAX arrays to enable static type checking
- **readable-number** - Parses and converts written numbers (e.g., "one hundred") to digits
- **triton** - NVIDIA's domain-specific language for writing efficient GPU kernels (requires CUDA)
- **kenlm** - Efficient implementation of KenLM n-gram language models
- **fasttext** - Facebook's library for text classification and word vector representations
- **mmh3** - MurmurHash3: fast, non-cryptographic hash function (used for fingerprinting)
- **bitarray** - Space-efficient array of bits with useful operations
- **matplotlib** - Comprehensive library for creating static, animated, and interactive visualizations
