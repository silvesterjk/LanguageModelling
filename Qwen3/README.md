Qwen3 0.6B – Training From Scratch
==================================

This repository will contain code to train a **Qwen3‑style 0.6B language model from scratch**:
model definition, tokenizer, data pipeline, and training scripts.

Status
------

Work in progress. APIs, configs, and scripts will evolve as code is added.

High‑Level Workflow
-------------------

- Set up a Python environment and install dependencies
- Prepare a text dataset and tokenizer
- Run the training script to pretrain the 0.6B model

More detailed instructions and examples will be added as the implementation matures.
